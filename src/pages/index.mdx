## Overview

etchJS adds programmatic patterns to your DOM elements. It's tiny, ships vanilla JS and
React adapters, and generates every pattern client-side.

## Quick Start

```bash
npm install etchjs
```

```html
<div data-fill="stipple" data-fill-density="60" data-fill-color="#ff4d4d"></div>
```

## Features

- Lightweight and dependency-free
- Vanilla JS and React adapters
- Client-side pattern generation, so it's SSR-safe
- Interactive, live pattern controls
